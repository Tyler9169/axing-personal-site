# 阿星 · 叶昊霖的个人网站

米白、墨黑与橄榄色的简洁个人网站，包含个人介绍、工作经历与成果、生活图集和微信联系方式。

## 代码结构

- `index.html`：页面内容和结构。
- `style.css`：网页视觉样式与手机、平板适配。
- `script.js`：移动菜单、分类图集、照片灯箱、工作详情和微信复制。
- `assets/`：经 WebP 优化的照片与工作截图。
- `.nojekyll`：以静态文件方式发布，无需编译。

微信：`alpha-deadpool`。修改时需同步更新 HTML 和 JavaScript 中的微信号。

## GitHub Pages

在仓库 **Settings → Pages** 中，将发布源设为 **Deploy from a branch**，选择 **main** 分支和 **/(root)** 目录并保存。以后提交到 main 的更新会自动发布。

不需要安装依赖、后端服务或构建工具。浏览器打开首页即可预览；复制功能在 HTTPS 或 localhost 下使用剪贴板 API，其余环境提供手动复制提示。

页面内容与图片来自用户提供的飞书个人说明书，自我介绍视频通过飞书入口观看。
