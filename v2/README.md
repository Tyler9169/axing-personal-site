# 阿星个人网站 · 第二版

独立设计版本，入口为 `v2/index.html`。原版保留在仓库根目录。

公开网址：https://tyler9169.github.io/axing-personal-site/v2/

本版使用原生 HTML、CSS 和 JavaScript，复用 `../assets/` 中的真实照片和工作截图，无构建依赖。

从仓库根目录启动任意静态文件服务器，然后打开 `/v2/`。需要让服务器同时提供仓库根目录的 `assets/`，不要只把 `v2/` 作为服务根目录。

设计采用奶油白、深橄榄绿、衬线大标题与杂志式摄影布局。交互包括移动导航、四组相册筛选、键盘切换照片、工作详情弹窗、微信复制，以及上线后的网址分享。本地预览不会复制无法公开访问的 localhost 链接。

已检查 320px、390px、768px、1440px 布局和主要交互。GitHub Pages 从 `main` 分支发布，新版位于 `/v2/`，根目录仍为原版。
