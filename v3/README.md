# 阿星的灵感岛 · 第三版

一个可驾驶探索的 3D 个人网站，入口为 `v3/index.html`。公开访问：https://tyler9169.github.io/axing-personal-site/v3/ 。原版和第二版保持各自的入口。

## 体验

- 四个空间：关于我的小屋、创作展厅、生活花园、你好（联系空间）。
- 首屏小车沿道路默认自动循环，可手动暂停；系统要求减少动态效果时也不会默认暂停巡航。点击“开始探索”后，小车先沿安全路线返回起点，再进入手动探索。
- WASD / 方向键驾驶，空格刹车，Shift 加速。驶入地点圆圈自动打开内容；关闭后需驶离再返回，避免重复弹窗。E 或 Enter 保留为手动入口。
- 放大导航、地点标签与阅读文字，增加文字对比度；标题用衬线字，正文与操作使用清晰的系统黑体。
- 点击地点、顶部导航或小地图，可以自动避开场景障碍前往目的地。
- 拖动旋转视角，滚轮或双指缩放，M 切换全岛视角，R 回到起点。
- 手机提供方向键和刹车按钮。阅读弹窗支持键盘关闭、大图浏览、照片筛选与微信复制。
- 四个地点的发现进度仅保存在当前浏览器，不收集或上传访客数据。
- WebGL 不可用时，顶部导航仍可打开所有内容，也可以直接进入完整图文版。

## 本地运行

从仓库根目录启动静态文件服务器，例如 `python3 -m http.server 4174 --bind 127.0.0.1`，再打开 `http://127.0.0.1:4174/v3/`。必须从仓库根目录提供服务，因为图片复用 `../assets/`，图文版链接指向 `../v2/`。

运行驾驶和路径测试：`node --test v3/tests/driving.test.mjs`。

## 实现与来源

原生 HTML / CSS / ES Modules，Three.js 0.180.0 的 WebGL 渲染器。依赖文件随站点提供，不依赖运行时第三方 CDN。原始空间、建筑、植物、自行车、车辆与角色均使用代码构建；摄影与作品数据来自用户已有的个人说明书与网站素材。

交互方向参考 [Bruno Simon 的作品网站](https://bruno-simon.com/)，场景和视觉设计独立实现。图文内容与色彩延续前两版的奶油白、橄榄绿及杂志式排版。
